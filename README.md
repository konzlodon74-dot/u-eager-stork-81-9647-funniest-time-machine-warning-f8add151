A tiny Python program (stdlib only) that writes the funniest one-line warning label for a time machine to `/output/entry.txt`. The label is delivered in the flat voice of a real safety notice: it turns the classic hazard of meeting your own past self into the joke, and saves the sting for the last three words — your double does not merely know what you will say, he already hates it.

Run it with `python3 main.py`. It creates `/output/` if needed and writes exactly one line (95 characters), well within the 120-character gate.
